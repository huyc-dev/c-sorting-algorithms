# C Sorting Algorithms (C语言排序算法)

这是我的计算机专业学习笔记，用 C 语言实现了常见的经典排序算法。

## 📂 包含的算法
*    冒泡排序 (Bubble Sort)
*    插入排序 (Insertion Sort)
*    选择排序 (Selection Sort)
*    快速排序 (Quick Sort)
*    合并排序 (Merge Sort)
*    堆排序 (Heap Sort)
*    基数排序 (Radix Sort)
*    字符串选择排序 (Selection Sort for Strings)

## 🔧 如何运行
确保你的电脑安装了 C 语言编译器（如 GCC），然后：
```bash
# 例如编译并运行冒泡排序
gcc bubble-sort.c -o bubble-sort
./bubble-sort
